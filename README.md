# 🎵 音乐下载器

一个**单文件、免安装**的网易云音乐无损下载工具。双击运行，自动打开浏览器界面。

- **体积**：约 11 MB（单文件 exe，自带运行时，无任何依赖）
- **平台**：Windows x64
- **界面**：本地网页（默认 `http://127.0.0.1:18923`）

---

## 快速开始

1. 双击 `音乐下载器.exe`
2. 程序会启动本地服务并**自动打开浏览器**（若未自动打开，手动访问提示的地址）
3. 点右上角 **设置**，粘贴你的网易云 **Cookie**（下载无损需要 VIP 登录态）
4. 搜索歌曲 → 勾选 → **下载选中（无损 FLAC）**

关闭那个黑色控制台窗口即可退出程序。

## 功能

| 功能 | 说明 |
|---|---|
| **搜索** | 按歌名 / 歌手 / 专辑关键词搜索 |
| **专辑批量** | 点击结果中的**专辑名**展开整张专辑，一键全选下载 |
| **音质可调** | 无损优先（无无损自动降级 MP3）／仅无损／MP3 320k／MP3 192k |
| **歌词** | 自动保存同名 `.lrc` |
| **封面** | 自动下载专辑封面（800×800），并可写入音频标签 |
| **标签** | FLAC 写 Vorbis Comment，MP3 写 ID3v2.3；含 标题/艺术家/专辑/专辑艺术家/曲序/年份 |
| **选择文件夹** | 设置里点「浏览…」调用 Windows 原生文件夹选择器 |
| **命名规则** | 可选 `01. 歌名`（按曲序）或 `歌手 - 歌名` |
| **断点友好** | 已存在的封面不会重复下载；请求失败自动重试（4 次退避） |

## 如何获取 Cookie

1. 浏览器登录 <https://music.163.com>
2. 按 `F12` 打开开发者工具 → **Network** 标签
3. 刷新页面，点任意一个 `music.163.com` 请求
4. 在 **Request Headers** 中找到 `Cookie:`，整段复制
5. 粘贴到本软件的「设置 → 网易云 Cookie」并保存

> Cookie 仅保存在本机 `%APPDATA%\音乐下载器\config.json`，不会上传到任何地方。
> 若担心安全，用完后可在网易云「设置 → 退出所有设备」使旧会话失效。

## 常见问题

**Q：提示"无法获取无损地址"？**
- 未配置 Cookie，或该曲目本身没有无损版本（部分老歌 / 翻唱只有 128k）
- 确认你的账号是 VIP 且该曲目支持无损

**Q：提示"服务端返回空响应（可能被限流）"？**
- 程序已内置自动重试（最多 4 次，递增退避）。若仍失败，稍后再试或减少一次下载的数量

**Q：下载目录在哪？**
- 默认 `桌面\音乐下载`，可在设置中修改
- 每张专辑会自动建独立子目录

**Q：端口被占用？**
- 程序会从 18923 起自动向后寻找可用端口，并打印实际地址

**Q：能下载 MP3 吗？**
- 可以。设置里「音质偏好」选择：
  - **无损优先，无无损时降级 MP3**（推荐）
  - **仅无损**（无无损则报错）
  - **MP3 320kbps** / **MP3 192kbps**
- MP3 同样会自动写入 ID3v2.3 标签与内嵌封面

**Q：点「浏览…」没反应？**
- 对话框会弹出在当前窗口最前；若被遮挡，检查任务栏
- 该对话框使用系统原生控件，不支持自定义标题文字（显示为系统默认的「浏览文件夹」）

## 技术说明

- **.NET 8** 编写，`PublishSingleFile` + `PublishTrimmed`（full）打包
- **零第三方依赖**：HTTP 用 `SocketsHttpHandler`，页面服务用 `HttpListener`，JSON 手工构建（避免裁剪反射问题）
- **FLAC 标签**：自行实现 Vorbis Comment 与 PICTURE 元数据块读写，并解析 JPEG/PNG 尺寸
- **MP3 标签**：自行实现 ID3v2.3 帧写入（文本帧用 UTF-16+BOM 保证中文兼容，APIC 内嵌封面）
- **文件夹选择**：`SHBrowseForFolderW`，并**刻意避开结构体编组**——改为 `AllocHGlobal` 手工按内存布局写入字段，否则 full-trim 会移除编组元数据并在运行时报 `TypeLoadException`
- **weapi 协议**：AES-128-CBC 双重加密 + 裸 RSA（`BigInteger.ModPow`），与网易云客户端一致
